### [1] [COPASI Skills: Agent Skills for COPASI analyses through Basico](https://arxiv.org/abs/2611.18115)
*Frank T. Bergmann,Sven Sahle*

Main category: q-bio.QM

TL;DR: 该论文提出了COPASI Skills，即一组面向AI助手的指令文件（每个含SKILL.md），用于指导助手通过Python接口Basico驱动COPASI完成生化模型分析任务。


<details>
  <summary>Details</summary>
Motivation: 生化模型以反应网络刻画分子物种的产生、消耗与转化，为系统动力学分析和计算实验提供定量框架。COPASI是广泛使用的模拟分析工具，其功能已通过Basico开放给Python，但对研究者而言仍需掌握具体调用流程；论文希望让研究者以自然语言直接获得时间过程、拟合或已发表模型等分析结果。

Method: 构建一套"技能"集合：每个技能为一个目录，内含SKILL.md文件。文件顶部简短描述说明该技能的适用场景，其余部分规定应进行哪些调用、应写出哪些文件，以及应额外选用哪些相邻技能。助手据此匹配并执行单一分析，将表格或报告与模型文件一并输出。代码以两条款BSD许可证发布在GitHub仓库。

Result: 实现了COPASI Skills的指令文件集合并在GitHub开源发布（BSD 2-clause）。研究者可用日常语言请求时间过程模拟、参数拟合或获取已发表模型，助手按对应技能执行并在模型旁生成表格或报告。

Conclusion: 通过将COPASI/Basico的操作流程封装为可复用的技能指令文件，降低了自然语言驱动生化建模分析的门槛，为AI助手与科学计算工具的衔接提供了一种轻量、可扩展的组织范式。

Abstract: Biochemical models represent biological systems as networks of reactions that describe the production, consumption, and transformation of molecular species over time. These models provide a quantitative framework for analyzing system dynamics and enable computational experiments that complement traditional wet-lab approaches, helping researchers gain mechanistic insight and make predictive assessments of biological behavior. COPASI is a widely used program for simulating and analyzing those models. These tasks are made availabe to Python through Basico. COPASI Skills is a set of instruction files that tell an assistant how to drive Basico for one analysis at a time. Each skill is a directory containing a `SKILL.md` file. A short description at the top tells the assistant when the skill applies, and the rest of the file states which calls to make, which files to write, and which potential neighboring skill to choose additionally. A researcher can ask for example, in ordinary language, for a time course, a fit, or a published model. The assistant follows the matching skill and leaves tables or a report next to the model. The collection is released under a two-clause BSD license from [https://github.com/fbergmann/copasi-skills](https://github.com/fbergmann/copasi-skills).

### [2] [S1Pert: Scalable Target-Specific Gene Response Prediction with System-One Intelligence](https://arxiv.org/abs/2611.17705)
*Xiaoqi Sheng,Hou wang,Yan Liang,Yutong Li,Wenhao Du,Tinghe Zhang,Jiawen Liu,Hongmin Cai*

Main category: q-bio.GN

TL;DR: S1Pert 是一个"System-One"式非自回归在线推理框架，用于预测未见基因扰动下的转录组响应，通过统计检验区分可靠标签、冻结编码器提取可复用表征、离线缓存成对交互，并借助层次交叉注意力解码器与跨目标成对排序抑制对历史响应频率的依赖。


<details>
  <summary>Details</summary>
Motivation: 将 CRISPR 筛选扩展到海量"靶标-基因"组合需要预测未见扰动的转录响应。但现有模型可能通过复现历史基因级响应频率（而非真正区分不同扰动效应）取得较好的总体指标；同时转录组尺度预测还面临响应标签不确定（不可靠标签）与数百万对计算冗余的挑战。

Method: 1）用方向性 Welch 检验与等效性检验，将统计支持的响应与不确定观察区分开；2）用冻结的 System-One 编码器提取扰动靶标、查询基因与历史证据的可复用语义表征；3）离线计算并缓存紧凑的成对特异性交互；4）轻量层次交叉注意力解码器整合上述表征，并结合跨目标成对排序与同步历史证据 dropout，降低对基因级响应频率的依赖；5）非自回归在线推理。

Result: 在多种细胞情境下的大量实验中，S1Pert 在提升目标特异性响应区分能力的同时，保持了可靠预测与高效推理。

Conclusion: 结果说明 System-One 决策学习在超越历史基因级响应倾向、实现可扩展扰动-响应预测方面具有潜力；代码已开源。

Abstract: Predicting transcriptional responses to unseen genetic perturbations is essential for extending CRISPR screens across vast target--gene combinations. However, models can achieve strong aggregate predictive performance by reproducing historical gene-level response frequencies without adequately distinguishing the effects of different perturbations. Reliable prediction at the transcriptome scale is further challenged by uncertain response labels and redundant computation across millions of target--gene pairs. We present S1Pert, a System-One framework for target-specific gene response prediction with non-autoregressive online inference. S1Pert combines directional Welch tests and equivalence testing to distinguish statistically supported responses from inconclusive observations. A frozen System-One encoder extracts reusable semantic representations of perturbation targets, query genes, and historical evidence. Compact pair-specific interactions are then computed and cached offline. A lightweight hierarchical cross-attention decoder integrates these representations with cross-target pairwise ranking and synchronized historical-evidence dropout to reduce reliance on gene-level response frequencies. Extensive experiments demonstrate that S1Pert improves target-specific response discrimination while maintaining reliable prediction and efficient inference across diverse cellular contexts. These findings highlight the potential of System-One decision learning for scalable perturbation-response prediction beyond historical gene-level response tendencies. The source code is publicly available at https://github.com/liujiawen-jpg/S1Pert.

</details>
